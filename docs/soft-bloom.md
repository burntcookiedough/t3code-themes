# Soft Bloom

How Soft Bloom is built. Everything here is generated by `source/soft-bloom/generate.py`. The rules it shares with the other themes (selectors, glass recipe, performance, pitfalls) are in [THEME-GUIDE.md](THEME-GUIDE.md).

## Palette

| Name | Value | Used for |
|---|---|---|
| base | `#09090b` | the scene's background, the canvas role |
| deep / ink | `#060607` | sidebar and chrome tint, code blocks, popups (darker than the scene) |
| surface / raised | `#121215` / `#18181c` | solid fallbacks for cards and rows |
| text | `#ede6d6` | main text (≈ 16:1 on base) and **every edge**: hairlines, focus rings, glows, all at low alpha |
| muted | `#9b968c` | secondary text (≈ 6.8:1) |
| faint | `#938d84` | placeholders, muted icons (≈ 6:1) |
| cream (accent) | `#f1e7d0` | links, the caret, primary buttons, checked switches, the art |
| sage / rose | `#9ec8b8` / `#f0a3a8` | status: done and added lines, errors and removed lines |

Edges are always the text colour, never the accent, so the whole theme reads as one material.

## Layers

```
[data-slot="sidebar-wrapper"]       isolated stacking context; transparent background
    ::before     fixed compositor layer: base gradient, vignette, stipple grain,
                 pixel sparkles and a dithered halo, faded under the text column
    ::after      fixed compositor layer: the big dithered star in the bottom-right gutter
  [data-slot="sidebar-inner"]       frosted glass: deep 50%, blur 14px
  [data-chat-header]                glass bar: deep 72%, blur 8px
  conversation                      transparent; user bubbles 92% solid
  [data-slot="composer-shell"]      T3's own chat-box glass, tuned: 50%, blur 16px
  [data-thread-details-card]        the sidebar's glass: deep 60%, blur 14px
  [data-workspace-area="panel"]     right panel: deep 72%, matching the chat header; no blur
    [data-right-panel-tabbar]       transparent, including the native-controls inset
popups [data-slot$="-popup"]        ink at Glass opacity + 12% (small popups + 14%), blur 24px
                                    sheets: ink 97%, no blur (they slide)
[data-slot$="-backdrop"]            one dim layer for every modal: near-black 62%, blur 4px
```

The scene's two pseudo-elements are fixed to the window, behind the content at `z-index: -1`, with `pointer-events: none` and `will-change: transform`. The wrapper's `isolation: isolate` keeps them above the page background. They span the sidebar, chat, Pull requests page and right panel without re-rasterising the art as panes slide. Popups are portaled outside the wrapper but still blur it, because `backdrop-filter` sees everything painted behind them.

The sparkles/halo fade lives inside its SVG so it masks only that art, leaving the shared layer's base gradient and grain untouched. The star keeps its separate CSS mask and 42% opacity. Pattern spacing, corner offsets and sidebar blur are unchanged.

## Colour roles

Almost every surface comes from the colour roles, so screens the CSS never targets still match. The glass values are roles too: `border` is text at 7.5%, `input` 12%, `accentSurface` (hover) 6.5%, `muted`, `secondary` and `surfaceRaised` 5–5.5%; `surface` (cards) is `rgba(22,22,26,.55)`, `surfaceOverlay` (popover fallback) `rgba(16,16,19,.86)`, `codeBackground` `rgba(6,6,7,.72)`, chrome and toolbars `rgba(6,6,7,.55)`. Status panels (`errorSurface`, `warningSurface`, `updateSurface`) are the ink glass tinted 20% toward their status colour.

From CSS, because they aren't roles: `--surface-grain: none` (the scene has its own grain), `--info-foreground` (moonlight `#b9c3d6` instead of T3's bright blue for "Working"), and `--success`, `--success-foreground`, `--diff-addition-foreground`, `--diff-deletion-foreground` (sage and rose instead of T3's emerald and red).

Inside big modals the theme sets a second layer: a **solid** `--background` (`#08080a`, because switch knobs and select triggers paint with it), `--sidebar: transparent`, `--card` faint, and quiet row states. Settings' navigation sits a shade darker.

## The art

- **Dither filter** (`dither_filter`): blur the shape, posterize it into about 12 bands, subtract stretched fractal noise, then hard-threshold. The result is stippled dots whose density follows the glow. The noise is stretched (`slope 3.4, intercept -1.2`) so the change from solid to empty isn't abrupt, and the threshold bias is `0.44` so areas with no glow stay empty.
- **Big star** (`bloom_svg`): a five-point outline with a hollow centre.
- **Pixel sparkles** (`stars_svg`): `crispEdges` plus-shapes with a few tiny dithered glows.
- **Stipple grain** (`stipple_grain`): thresholded high-frequency noise, sparse 1px dots.

The scene is static on purpose: anything moving behind glass makes the app lag (§8 of the guide).
